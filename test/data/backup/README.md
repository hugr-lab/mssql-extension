# Backup samples (spec 085 task 10)

Small SQL Server backups for the backup reader's tests, **synthetic and made on a clean instance**:
`generate.sh` runs `test/backup/gen/generate.sh` (SQL Server 2025), which starts a throwaway SQL
Server container of its own, runs `test/backup/gen/samples.sql` (a generated database,
`bak_sample`), saves the golden `RESTORE HEADERONLY` / `LABELONLY` / `FILELISTONLY` output of every
backup next to it (`<name>.headeronly.txt`, …) with `sets.txt` naming each set's files, copies the
backups out and removes the container. The oracle lane runs the same generator on 2017–2025
(spec 085 PR 2a). No backup of any other instance is ever committed here (spec 085 T4); the
repository ignores every other `*.bak`.

| file | what |
|---|---|
| `full.bak` | full, WITH CHECKSUM |
| `full_xpress.bak`, `full_zstd.bak` | full, COPY_ONLY, compressed with MS_XPRESS / ZSTD |
| `stripe_1.bak` + `stripe_2.bak` | a full striped in two |
| `stripe_zstd_1.bak` + `stripe_zstd_2.bak` | a ZSTD-compressed full striped in two (the media label's family fields) |
| `diff.bak` | a differential over `full.bak` |
| `log.trn` | a log backup after it |
| `sets.txt` | one line per backup set, `name\|file[,file]`: the sets the comparison reads, in order |
| `<set>.headeronly.txt`, `.labelonly.txt`, `.filelistonly.txt` | the server's `RESTORE` answers for the set (`sqlcmd -s '\|' -W`) |

Regenerating also writes `server.txt` (the server's version, which the comparison checks against
`software_version`); the committed samples predate it and have none.

`make test-backup-golden` compares `mssql_backup_info` with the golden files, field by field
(`test/backup/compare_info.py --expect-major 17`, which also asserts that `sets.txt` names exactly
the sets a 2025 server makes); CI runs the same comparison on every pull request. Regenerate (needs
Docker):

```bash
test/data/backup/generate.sh
```

`VERSION` defaults to `2025` and the script refuses any other: the samples, their golden files and
`test/sql/backup/` are 2025's, and an older server would leave 2025's ZSTD backups beside its own
sets. Another version goes to a directory of its own
(`OUT=/tmp/bak VERSION=2019 test/backup/gen/generate.sh`). `IMAGE=` (a newer 2025 image) is passed
through to the generator.

The SA password is generated by the script and held in its environment: docker is given the
variable's name, never its value, so it is on no command line (`docker inspect` shows it while the
container lives). The container is removed when the script ends, however it ends.
